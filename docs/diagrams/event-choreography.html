Correlation

Every message in a given order's chain carries CorrelationId = OrderId, so the whole sequence above can be traced as one thread through five independent services' logs.

Delivery guarantee

A handler writes its entity changes and an outbox row in one SaveChangesAsync. A background OutboxProcessor polls every 5s and publishes — so a state change is never announced before it's actually saved.

The one exception

Ordering calls Catalog over plain HTTP to validate line items and snapshot pricing at order-creation time — the single synchronous hop in an otherwise fully asynchronous system.
